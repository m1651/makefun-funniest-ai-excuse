A make.fun bounty entry for "The Funniest AI Excuse": a program that writes
one original line — the funniest excuse an AI agent could give after failing
a task — to `/output/entry.txt`.

The line (121 characters):

> I did finish the report — it's saved in a folder called
> 'final_v2_FINAL_real_this_time,' which even I can no longer find.

Run it with `python3 main.py`. It validates the line (non-empty, single
line, at most 200 characters, valid UTF-8) before writing it
deterministically to `/output/entry.txt`.
